DSA Project

Implementation of Essential Data Structures & Algorithms in Python

Presented by: DSA Project Group

Team members: Al-Qaraghuly Mostafa, Khiem Nguyen, The Bui, Gihan Fernando

Language: Python 3 (standard library only)

From-scratch implementation of core data structures and algorithms, demonstrated through scenario-based programs.

Project Structure

  • src/dsa/ — Core logic code (from-scratch implementations). Contains linear/ (arrays, linked lists, stacks, queues), trees/ (binary tree, BST, AVL), hashing/ (hash functions, chaining, open addressing), plus sorting.py, searching.py, and stats.py for complexity tracking.
  • scenarios/ — Scenario-based demonstrations that apply the structures/algorithms to real-world contexts.
  • tests/ — Unit tests validating correctness across all components, covering edge cases and invariants.
  • performance/ — Performance analysis scripts and reports comparing algorithms/structures across input sizes and distributions.

main.py ties everything together to run scenarios.

How We Implemented the Code

  • From scratch: No built-in high-level containers used in implementations (no list.sort, no dict/set). Everything built from nodes, lists/arrays, and buckets/slots.
  • Standard library only: Pure Python 3.9+ with no external dependencies.
  • Modular design: Clear separation by category (linear/, trees/, hashing/) with shared utilities like stats.OpStats for tracking comparisons/swaps.
  • Complexity-conscious: Time and space complexity documented in docstrings for methods and functions.

Implementation Details

  • Linear structures: Node-based linked lists, array-backed stacks/queues with proper bounds checking and clear error handling.
  • Trees: Recursive implementations with careful balance logic for AVL (propagating root changes via return values). Both recursive and iterative traversals provided.
  • Hashing: Custom hash functions (division, polynomial, djb2). Chaining with load-factor-based resizing; open addressing with linear/quadratic (triangular) probing and tombstone deletions.
  • Algorithms: Sorting/searching implemented from scratch with optional OpStats for instrumentation and performance analysis.
  • Validation-driven: Extensive unit tests, scenario validation, and automated reports ensure correctness.

Key Approach

  • Test-first validation: Each structure/algorithm validated against edge cases and invariants.
  • Scenario-driven design: Real-world use cases guide API design and ensure practical applicability.
  • Performance tracking: Instrumentation via OpStats enables empirical comparison across inputs/distributions.
  • Clean interfaces: Consistent method naming and error semantics across all implementations.
